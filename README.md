# UNIPARC AI Company — V1

Founder-controlled AI operating system for UNIPARC.

## North Star
Build UNIPARC into a profitable, culture-first Indian Gen-Z apparel brand with strong community, repeatable sales, distinctive original products, operational excellence, and credibility for major IP partnerships.

## Organization
Founder / Board → CEO → CMO / R&D / Creative / Sales / Operations / Finance

## Core rules
- Founder retains final approval for high-impact decisions.
- Agents use evidence before recommendations.
- Brand Guidelines v1.0 is the source of truth.
- Content priority: CULTURE → COMMUNITY → DESIGN STORIES → UNIPARC IRL.
- Original-first IP policy.
- Creative generation may be automated; major publishing and spend remains approval-gated.
